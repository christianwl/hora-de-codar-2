# Desafios de Lógica

Coleção de 11 desafios de lógica de programação desenvolvidos originalmente durante o programa **Proprofissão (Instituto PROA)** no início de 2024.

## 📝 Sobre o Projeto
O objetivo central foi exercitar a lógica de programação utilizando JavaScript para resolver problemas matemáticos, condicionais e de estrutura de dados simples. 

## 🚀 Os 11 Desafios
O projeto executa as seguintes funções:
1.  **Maior de Dois:** Identifica o maior entre dois números.
2.  **Sinal do Número:** Verifica se um valor é positivo, negativo ou zero.
3.  **Maior de Três:** Retorna o maior entre três valores distintos.
4.  **Soma dos Maiores:** Soma os dois maiores números entre três informados.
5.  **Média Aritmética:** Calcula a média de 6 valores lidos.
6.  **Primeiro, Último e Maior:** Filtra e exibe informações específicas de um conjunto de 4 números.
7.  **Soma Inferior a 72:** Soma números informados que sejam menores que 72.
8.  **Média seletiva (0 a 10):** Calcula média apenas de notas válidas e retorna aprovação.
9.  **Verificação de Voto:** Checa se a idade permite votar no ano atual.
10. **Cálculo de Peso Ideal:** Baseado em altura e gênero (IMC).
11. **Micro Calculadora:** Executa as 4 operações básicas entre dois valores.

## 📈 Evolução e Atualizações

### Início de 2024 (Fase de Lógica)
* Desenvolvimento de todos os algoritmos em **JavaScript**.
* Uso de funções (`prompt`, `alert`) para interação via navegador/console.

### Atualização em 2025 (Fase Visual)
* **Integração Web:** Início da criação de uma estrutura em **HTML5** e **CSS3**.
* **Interface:** Estilização inicial para transformar os scripts de console em uma interface amigável para o usuário final.
* **Apresentação:** Organização do código para facilitar a demonstração visual das funções criadas.

### Atualização em 2026 (Refatoração e Engenharia de Software) 
* **Modularização (ES6 Modules):** Separação de responsabilidades com a divisão do código em módulos (`import/export`), facilitando a manutenção.
* **Clean Code & Refatoração:** Aplicação de métodos modernos de array como `.reduce()`, `.filter()`, `.sort()` e `.join()` para substituir loops complexos.
* **Arquitetura Reutilizável:** Criação de utilitários (`utils`) para manipulação de inputs e cálculos matemáticos, evitando repetição de código.
* **Documentação JSDoc:** Implementação de documentação técnica em inglês para funções utilitárias, descrevendo parâmetros e retornos.
* **Performance:** Substituição da função `eval()` por mapeamento de funções

## 🛠️ Tecnologias
* JavaScript (ES6+) (Módulos, Desestruturação, Spread Operator e Arrow Functions)
* HTML5 (Estrutura da interface)
* CSS3 (Estilização em progresso)
